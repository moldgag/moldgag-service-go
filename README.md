# moldgag-service-go

Service scris în **Go** pentru a servi aplicația **Moldgag** – o rețea socială pentru moldoveni.

🌐 Vizitează pagina oficială: [moldgag.github.io](https://moldgag.github.io/#)

## Despre Moldgag

**Moldgag** este o platformă socială în stil Telegram + Jodel + 9GAG, adaptată pentru comunitatea din Republica Moldova. Proiectul este open source și deschis colaborării.

## Acest repo

Acest repository conține serviciul backend scris în Go, care oferă API-ul aplicației Moldgag.
